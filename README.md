# Réel Inattendu — crédits des archives

Crédits détaillés des archives employées dans les documentaires de la chaîne
[Réel Inattendu](https://www.youtube.com/@ReelInattendu).

Chaque page recense, photographie par photographie : le fichier, l'auteur tel
qu'indiqué par la source, la page source, la licence exacte et son URL, les
modifications apportées et le minutage dans la vidéo.

Ces pages existent pour satisfaire les obligations d'attribution des licences
Creative Commons BY-SA, qu'un champ de description YouTube ne permet pas de
porter intégralement.
